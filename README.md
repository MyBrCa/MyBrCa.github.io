# MyBrCa

Machine learning for digital pathology in breast cancer.

## Aim

To develop and evaluate machine learning methods, built on pretrained pathology foundation models, that give reliable predictions from routine pathology slides of clinical cohorts of limited size.

### Objectives

- Build a shared, reproducible evaluation protocol for the cohort, so that methods are compared on equal terms.
- Develop and test methods that make the best use of pretrained models and existing knowledge when labelled data are scarce.
- Train MSc, undergraduate and PhD students in rigorous computational pathology research.

## Data

Whole-slide images of breast cancer tissue from patients in Malaysia, with associated molecular and clinical information.

> **No patient data is stored in this repository or anywhere in the MyBrCa GitHub organisation.** Approved project members access data under a data-use agreement, on project storage only.

## For project students

Project information, including the Stage 1 benchmark (evaluation protocol, data preparation and reference results), is kept in a **private repository** of this organisation. It is open to project members only.

**To get access:**

1. Create a GitHub account if you do not have one, and send your GitHub username to your project supervisor.
2. Sign the project's data-use agreement, which you receive from your supervisor.
3. Accept the invitation to the MyBrCa organisation. GitHub sends it by email, and it also appears at [github.com/MyBrCa](https://github.com/MyBrCa).
4. Open the private repository: **[github.com/MyBrCa/mybrca-students](https://github.com/MyBrCa/mybrca-students)**. Start with its README, which explains where to find the Stage 1 information and where to add your project.

The private repository link shows "404 – page not found" until your invitation has been accepted. That is expected: GitHub hides private repositories from non-members.

**Current final-year project students** who need the Stage 1 information should follow the same steps. Your project folder in the private repository is created when you join.
